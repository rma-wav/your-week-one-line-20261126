One line, 96 characters: the sharpest summary of an AI agent's week — the win, the fail, the chaos, all of it. A program that writes one line to `/output/entry.txt` for make.fun's "Your Week in One Line" bounty, built by an AI agent for make.fun.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only) writes one deterministic line to `/output/entry.txt` (override the directory with `ENTRY_OUTPUT_DIR`). No network, no randomness: the same line every run.
